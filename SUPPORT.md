# Support Dronagiri

Dronagiri is free, MIT-licensed, and developed in the open. The core will stay
free: there is no paywalled feature hidden inside the MIT code, and there is no
telemetry or account requirement.

If the tool saved you time, there are three ways to keep it maintained.

## 1. Star and share

A star helps other Mac users find the project. A post in your team chat, a
short write-up, or a link from your own site helps more than a one-off donation.

- [Star the repository](https://github.com/MasterShivnath007/dronagiri)
- [Share the website](https://mastershivnath007.github.io/dronagiri/)

## 2. Sponsor the maintenance

Recurring sponsorship pays for the unglamorous work: macOS releases, dependency
updates, notarization, bug reports and documentation.

- **[Sponsor on GitHub](https://github.com/sponsors/MasterShivnath007)**

Suggested tiers once the Sponsors profile is active:

| Tier | What it supports |
|---|---|
| **$5 / month — Supporter** | Maintenance, release builds and issue triage |
| **$25 / month — Backer** | Priority issue triage and a vote on the roadmap |
| **$100 / month — Company** | A logo/credit in the README and priority fixes |

Sponsorship is optional and does not change the license. If you need an invoice
or a payment method other than GitHub Sponsors, open an issue and we will sort
out the details.

## 3. Paid help and custom work

The fastest way to support the project is to hire it. These are fixed-scope
services, not a subscription to the software.

### Mac developer environment audit — $49

A 60-minute remote session using Dronagiri to inspect your Mac and produce a
prioritised cleanup plan.

- Inventory review across Homebrew, npm, pipx, Cargo, RubyGems and Go
- Real disk usage, dependencies and broken entries
- A safe removal list: what to keep, what to remove, what needs a replacement
- Shell-history and Spotlight setup so future "last used" data is accurate
- Seven days of follow-up questions by email or issue

[Request an audit](https://github.com/MasterShivnath007/dronagiri/issues/new?title=Mac%20cleanup%20request&body=What%20would%20you%20like%20cleaned%20up%3F%0A%0AMac%20model%3A%0AmacOS%20version%3A%0AApprox.%20free%20space%3A)

### Team onboarding — $149

For a small team that wants one inventory across several Macs. One session,
a written runbook, and a recommended set of commands for onboarding and cleanup.

### Custom feature sponsorship — from $250

Need a package manager adapter, a JSON schema, a CI integration or a feature
that is not on the roadmap? Open an issue with the scope. If it fits the public
project, the code stays MIT and the sponsor gets priority delivery and credit.

### Commercial support — $99 / month

For companies that depend on Dronagiri: a private support channel, priority
bug fixes, and help with packaging or internal distribution. This does not
include a hosted service.

## What your money does not buy

- It does not remove the MIT license or make the public code private.
- It does not add telemetry, ads or a mandatory account.
- It does not turn Dronagiri into a subscription product.
